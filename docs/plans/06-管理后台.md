# 06 · 管理后台（编辑部案头）

规格版本：阶段 3 之后的操作面
前置：阶段 1–3 已落地（公开只读 + 管理端 CRUD API）。**不改** `01`–`05` 已锁字段、表名、状态码。
本文件是 `/admin` 的唯一 UI 规格。接口仍以 `05` 为准。

技能依据：沿用公开站报纸身份，做成「划版台」而不是通用 dashboard。不做 LLM、不自动付印、不改公开 `mustRead` 形状。

## 1. 范围

做：

- Next.js 路由 `/admin/*`，同一仓、同一前端，不另起 admin 应用
- 登录 / 刷新 / 登出走已有 `POST /api/v1/auth/*`
- 专题、信源、早报、事件簇、审计的列表与编辑，全部打 `05` 的 admin API
- JWT 只放 `sessionStorage`（access + refresh + email），无 cookie、无 CSRF token
- 浏览器只打同源 `/api/v1`（Next rewrite → FastAPI）。**不要**设 `NEXT_PUBLIC_API_BASE`

不做：

- LLM 自动付印
- 公开页导航里挂「后台」入口（编辑自己敲 `/admin`）
- 改 `01`–`05`、改公开契约、改脉搏为实时聚合
- 用户注册、收藏、Redis、对象存储
- 管理端服务端渲染带密文（所有 admin 页 `"use client"`）

## 2. 视觉命题

公开站是报纸。后台是同一张纸上的**编辑部案头**：

- 沿用 `globals.css` 的 paper / ink / blue / red token，不另起仪表盘色板
- 左轨是稿签栏（早报 / 专题 / 信源 / 采集 / 审计），左侧 3px 油墨红竖线当「校改线」
- 中英字段永远对开，禁止按 `Accept-Language` 只显示一种
- slug、date、code 用等宽；draft 虚线稿签，published 实心「付印」章
- 不做大 hero、不做渐变卡片墙、不做通用 KPI 块

## 3. 路由

| 路径 | 职责 |
|---|---|
| `/admin/login` | 登录。已登录则跳 `next` 或 `/admin` |
| `/admin` | 案头：最近早报、草稿、信源异常、最近审计 |
| `/admin/briefings` | 早报列表 + 新建草稿 |
| `/admin/briefings/[date]` | 编辑早报（含脉搏快照）+ 当日簇列表 |
| `/admin/stories/new?date=` | 新建簇（date 可预填，目标日必须已有 briefing） |
| `/admin/stories/[slug]` | 编辑 / 删除簇 |
| `/admin/topics` | 专题列表 + 创建 / 改 / 删 / 下架 |
| `/admin/sources` | 信源列表 + 创建 / 改 / 删 / 隔离 |
| `/admin/pipeline` | 采集案头：定时 3 次/天、抓 RSS、入库、template 划版 |
| `/admin/audit` | 审计时间线，只读 |

公开页面迁到 `src/app/(site)/`，根 layout 不再包 Header/Footer。URL 不变。

## 4. 鉴权

- 登录 body：`{ email, password }`，成功把 `accessToken` / `refreshToken` / `admin.email` 写入 `sessionStorage` 键 `ai-report.admin.session`
- 所有 `/api/v1/admin/*` 带 `Authorization: Bearer <access>`
- 401 先 `POST /auth/refresh` 轮转再重试一次；refresh 失败清 session，跳 `/admin/login?next=`
- 登出：`POST /auth/logout`（access + refreshToken），无论成败清本地
- 登录失败文案用后端原句（`Invalid credentials.`），**不要**在 UI 上区分「用户是否存在」
- 停用账号 403 `Account disabled.` → 清 session
- 关页即丢（sessionStorage）。不写 localStorage

## 5. 写接口纪律（UI 必须遵守）

- 未知字段会 422。表单只提交 `05` allowlist
- 整数用 JSON number，不用 `"1"`
- 空 URL 发 `null`，禁止 `http://`
- `lastFetch` 空则 `"—"`（em dash U+2014）
- citation 无目录 code 时 `sourceCode` 发 `null` 或不带
- 簇 PATCH 按 `05` **整包**提交 `date, topicSlug, section, title, dek, synthesis, timeline, sources`；`must` 必带 `rank`，`more` 不带 `rank`
- 脉搏是快照：编辑器改的是数字本身，禁止用簇数量回填 `pulse.clusters`
- 删 published 早报会 409，按钮直接禁用；先 unpublish
- 有簇的 topic、有 citation 的 source 删不掉，UI 显示后端 message
- 不要 publish 未来日做「试试」——那会把公开 `/briefings/today` 拽走

## 6. 页面要点

### 登录

邮箱 + 密码。placeholder 可用 `admin@example.com`，密码不预填。限流 5/min 时展示 429。

### 案头

- 当前账号 email
- 窗口内早报：published / draft 分列
- `status=bad` 或 `isQuarantined` 的信源
- 最近 8 条审计
- 主操作：新建早报、去今日公开页（`/d/{currentPublished}`）

### 早报编辑

可改：`title`、`weekday`、`moreHeading`、`lede`、`updatedAt`、`pulse`。
不可改：`date`。状态只走 Publish / Unpublish。
lede、pulse.topics 可增删行。保存后留在本页，顶栏出成功条。

### 簇编辑

创建页 slug 可写；编辑页 slug 只读。
synthesis / timeline / citations 可增删。空数组允许。
中英任一空禁止提交（后端 `min_len=1`）。

### 采集

调度面板展示 `enabled` / 三个点 / `nextRunAt` / 上一轮 tick。
「立即跑一轮」走 `POST /admin/pipeline/tick`（抓取 + 当天划版，timeout 120s）。
手动抓取、按日划版按钮保留。已付印日划版 409；定时 tick 则记 `skipped_published`。
